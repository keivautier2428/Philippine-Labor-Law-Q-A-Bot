# Philippine Labor Law Q&A Bot

A Retrieval-Augmented Generation (RAG) capstone project for IS Professional
Elective #4 (Generative AI Systems). The bot grounds its answers in the
Philippine Labor Code (Presidential Decree No. 442) so workers, HR staff, and
small-business owners can ask plain-language questions about labor law and get
answers cited back to the actual statute.

## Checkpoint 3 — RAG Orchestration & Working Application (Semi-Final)

Status: code complete and unit-tested offline (26 tests). Live demo transcript
(`docs/rag_demo_report.md`) and retrieval eval (`docs/rag_retrieval_eval.md`) are
generated by running the commands below; they are not committed until run.

10. **Ingestion Pipeline** — [`src/ingestion/pipeline.py`](src/ingestion/pipeline.py):
    parse (.txt/.md/.pdf) -> clean (reuses Checkpoint 1) -> article-aware chunk -> embed -> store in
    Chroma. Idempotent (per-document content hash), isolates bad files, `--dry-run` / `--reset`.
    To add documents: drop them in `data/incoming/` and rerun it.
11. **RAG Application** — [`src/rag/chain.py`](src/rag/chain.py) (LangChain + LangGraph),
    CLI in [`src/rag/cli.py`](src/rag/cli.py). Flow: route -> retrieve -> generate -> verify ->
    (regenerate once) -> finish. Verification = free citation check (every cited article must be in the
    retrieved context) + the Checkpoint 2 LLM self-check, which now loops back instead of only logging.
12. **Conversational Memory** — LangGraph `InMemorySaver`, one thread per session; follow-ups are
    rewritten into standalone queries by the router using recent history.
13. **Framework Comparison Note** — [`docs/framework_comparison_note.md`](docs/framework_comparison_note.md)
14. **Live demo** — [`src/rag/demo.py`](src/rag/demo.py): 6 questions in one session (2 memory follow-ups,
    1 in-scope-but-not-in-corpus, 1 out-of-scope refusal). `src/rag/evaluate.py` measures retrieval
    hit@k and calibrates the relevance threshold with zero LLM calls.

```bash
pip install -r requirements.txt
python -m src.ingestion.pipeline      # build the v3 index (first run downloads MiniLM)
python -m src.rag.evaluate            # free: retrieval hit@k + threshold calibration
python -m src.rag.cli                 # chat (3 Gemini calls per answered question)

```

Free-tier quota: Gemini allows ~20 requests/day on this setup. Use `--no-self-check` to cut
calls per question from 3 to 2, and `src/rag/evaluate.py` for repeated retrieval checks.

## Running the Pipeline

```bash
# Checkpoint 1: clean/tokenize the raw Labor Code articles, then embed them
python src/preprocessing/preprocess.py
python src/embeddings/generate_embeddings.py

# Checkpoint 2: build the vector index, prove retrieval works, compare
# distance metrics, then run the full prompt pipeline against Gemini
python src/vectorstore/build_index.py
python src/vectorstore/query_demo.py
python src/vectorstore/distance_comparison.py
python src/llm/api_demo.py
```

Outputs land in `data/processed/` (cleaned JSON, `_corpus.jsonl`,
`embeddings.npy`, `embeddings_metadata.json`, the `chroma_db/` index) and
`docs/` (all reports referenced above).
